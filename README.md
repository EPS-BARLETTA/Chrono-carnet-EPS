# Chrono Carnet EPS

Application EPS optimisée iPad pour prendre les temps de plusieurs coureurs, enregistrer les passages et transférer les résultats vers le Carnet d’entraînement.

## Fonctions V1
- chronomètre principal
- ajout de plusieurs coureurs
- enregistrement tactile des passages
- temps cumulé + temps du tour
- annulation du dernier passage
- sauvegarde locale automatique
- transfert vers le Carnet d’entraînement
  - copier le HTML formaté + texte puis ouvrir le Carnet
  - exporter le même contenu en JSON pour import ultérieur

## Déploiement
Application statique compatible Vercel.
